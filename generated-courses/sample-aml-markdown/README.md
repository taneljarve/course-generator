# Sample: AML Fundamentals

This sample course exists so the Markdown workspace has a real folder and real `.md` files to preview before you connect the OpenAI API.

## Who this is for

- New compliance analysts
- Operations teammates entering fintech
- Anyone reviewing AML learning content in Markdown

## How to use this course

1. Read the overview first.
2. Open each day file from the left sidebar.
3. Use the preview tab to see the GitHub-style rendering.
4. Use the raw tab to inspect the actual Markdown file contents.

## Day-by-day outline

| Day | Focus | Output |
| --- | --- | --- |
| Day 1 | What AML is and why it matters | Shared vocabulary and basic context |
| Day 2 | KYC and red flags | A starter checklist for case review |

## What the real generator does

When the OpenAI API is connected, Opitee will create:

- one course folder
- one `README.md`
- one Markdown file per learning day

All generated content is saved inside `generated-courses/`.
