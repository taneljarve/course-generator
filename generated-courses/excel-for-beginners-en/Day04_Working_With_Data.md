# Day 4: Working with Data

## Learning Objectives

By the end of today you will be able to:
- Sort data alphabetically or numerically
- Filter data to show only what you need
- Remove duplicates
- Use Find and Replace
- Organize large datasets efficiently

## Key Concepts

**Sort**: Arrange data in order (A-Z, 1-9, oldest to newest).

**Filter**: Show only rows that meet certain criteria while hiding others.

**Duplicate**: Identical rows that can be removed for data quality.

**Find and Replace**: Quickly locate and change text throughout a spreadsheet.

## Guided Explanation

### Sorting Data

**Why sort?**
- Organize alphabetically (names, products)
- Organize numerically (lowest to highest, highest to lowest)
- Organize by date (oldest to newest)

**How to sort:**
1. Click any cell in your data range
2. Go to Data tab > Sort
3. Choose column to sort by
4. Choose A→Z or Z→A (or smallest to largest)
5. Click OK

Important: Excel sorts entire rows together, keeping data intact.

### Filtering Data

Filters let you show/hide rows based on criteria.

**How to use filters:**
1. Select your data (including headers)
2. Go to Data tab > Filter
3. Click dropdown arrows in header row
4. Uncheck items you want to hide
5. Only matching rows appear

**Multiple filters:**
- You can filter by multiple columns at once
- Only rows matching ALL criteria show

Example: Show only Widget sales over $100

### Find and Replace

Quickly find and change text.

**Find:**
1. Ctrl+F or Data > Find
2. Type what you're looking for
3. Click Find All or Find Next

**Replace:**
1. Ctrl+H or Data > Replace
2. Type what to find
3. Type replacement text
4. Click Replace or Replace All

Careful with Replace All—make sure you want to change everything!

### Removing Duplicates

Clean data by removing identical rows.

**How to:**
1. Select your data
2. Data tab > Remove Duplicates
3. Choose which columns to check
4. Click OK

## Practical Exercise

**Organize a Customer Database:**

1. Create sample data:
   - Headers: Name | City | Sales | Date
   - Add 8-10 rows of customer data with some duplicates and varied sales amounts
   - Example:
     - John Smith | New York | $500 | 1/15/2024
     - Sarah Jones | Los Angeles | $750 | 1/10/2024
     - Mike Brown | New York | $450 | 1/20/2024
     - etc.

2. **Sort the data:**
   - Sort by Sales (highest to lowest)
   - Notice entire rows stay together

3. **Apply filters:**
   - Add filters to headers
   - Filter to show only New York customers
   - Filter to show only sales over $500

4. **Find and Replace:**
   - Find all instances of "New York"
   - Consider replacing with "NY" (optional)

5. **Remove duplicates:**
   - If you added duplicates, use Remove Duplicates

6. Save the file
