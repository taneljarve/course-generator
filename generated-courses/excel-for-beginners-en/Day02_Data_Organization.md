# Day 2: Creating and Organizing Data

## Learning Objectives

By the end of today you will be able to:
- Format cells with colors, fonts, and alignment
- Resize rows and columns
- Apply number formatting (currency, percentages, decimals)
- Understand and use cell styles
- Create a professional-looking spreadsheet

## Key Concepts

**Cell Formatting**: Changing the appearance of cells (color, font, size) without changing data.

**Number Format**: How numbers display (as currency, percentages, dates, etc.).

**Alignment**: How content is positioned in a cell (left, center, right).

**Merge Cells**: Combining multiple cells into one larger cell.

## Guided Explanation

### Formatting Cells

To format cells:
1. Select the cell or range of cells
2. Right-click and choose "Format Cells" or use Ctrl+1
3. Choose formatting options

**Font Formatting:**
- Font type, size, bold, italic, underline
- Access from Home tab > Font group

**Cell Color:**
- Right-click > Format Cells > Fill tab
- Or use the fill color button on the ribbon

**Number Formatting:**
- Select cells with numbers
- Right-click > Format Cells > Number tab
- Choose format: Currency, Percentage, Date, etc.

Example formats:
- **Currency**: $1,234.56
- **Percentage**: 45%
- **Decimal**: 3.14
- **Date**: 1/15/2024

### Resizing Rows and Columns

**Column width:**
- Position cursor between column headers
- Drag to resize
- Double-click to auto-fit content

**Row height:**
- Position cursor between row numbers
- Drag to resize
- Double-click to auto-fit

### Alignment

- Select cells and use alignment buttons on ribbon
- **Left, Center, Right**: Horizontal alignment
- **Top, Middle, Bottom**: Vertical alignment

## Practical Exercise

**Create a Professional Price List:**

1. Start fresh or use your expense file
2. In A1, type: **PRODUCT PRICE LIST** (make it bold and centered)
3. Merge cells A1 and B1 (select both, right-click > Merge Cells)
4. Create headers in row 3:
   - A3: Product
   - B3: Price
   - C3: Stock
5. Add sample data:
   - A4: Widget | B4: 19.99 | C4: 45
   - A5: Gadget | B5: 29.50 | C5: 32
   - A6: Gizmo | B6: 14.75 | C6: 58
6. Format column B as Currency
7. Center align the Stock column
8. Make headers bold with background color
9. Resize columns to fit content
10. Save the file
