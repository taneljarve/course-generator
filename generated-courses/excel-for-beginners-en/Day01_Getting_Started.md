# Day 1: Getting Started with Excel

## Learning Objectives

By the end of today you will be able to:
- Identify the main components of the Excel interface
- Navigate between cells and worksheets
- Understand rows, columns, and cell references
- Enter and edit basic data in cells
- Save your work in Excel format

## Key Concepts

**Spreadsheet**: A grid-based document for organizing, calculating, and analyzing data.

**Cell**: The intersection of a row and column, identified by a letter-number reference (e.g., A1).

**Row**: A horizontal line of cells (numbered 1, 2, 3...).

**Column**: A vertical line of cells (lettered A, B, C...).

**Active Cell**: The cell you're currently working in (highlighted in blue).

**Worksheet**: A single sheet within an Excel file (you can have multiple sheets in one file).

## Guided Explanation

### The Excel Interface

When you open Excel, you'll see:

- **Ribbon**: The toolbar at the top with menus like File, Home, Insert
- **Name Box**: Shows the current cell reference (left side of formula bar)
- **Formula Bar**: Where you see and edit cell contents
- **Column Headers**: Letters A, B, C... across the top
- **Row Headers**: Numbers 1, 2, 3... on the left side
- **Sheet Tabs**: At the bottom, showing different worksheets

### Basic Navigation

- **Click a cell** to select it
- **Arrow keys** to move between cells
- **Ctrl+Home** to go to cell A1
- **Ctrl+End** to go to the last used cell

### Entering Data

1. Click the cell where you want to enter data
2. Type the data
3. Press Enter to move to the next cell
4. Or press Tab to move to the right

Data types Excel recognizes:
- **Text**: Names, labels, addresses
- **Numbers**: 42, 3.14, -5
- **Dates**: 1/15/2024
- **Formulas**: Start with = (we'll cover these later)

### Saving Your Work

- **Ctrl+S** or File > Save
- Choose **Excel Workbook (.xlsx)** for compatibility
- Give your file a descriptive name

## Practical Exercise

**Create Your First Spreadsheet:**

1. Open Excel
2. In cell A1, type: **Monthly Expenses**
3. In cell A2, type: **Category**
4. In cell B2, type: **Amount**
5. In cells A3-A6, enter: Groceries, Utilities, Transport, Entertainment
6. In cells B3-B6, enter any numbers (example: 150, 80, 40, 50)
7. Press Enter after each entry
8. Save the file as "My First Spreadsheet.xlsx"

## Reflection Questions

2. Why might using a spreadsheet be better than a piece of paper for tracking expenses?
3. What happens to data when you press Enter versus Tab?
