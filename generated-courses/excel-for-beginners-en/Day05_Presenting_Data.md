## Key Concepts

**Chart**: A visual representation of data (bars, lines, pie charts).

**Series**: The data being plotted (typically one column).

**Legend**: A key explaining what each color or bar represents.

**Chart Title**: The name describing what the chart shows.

**Page Break**: Where one printed page ends and another begins.

## Guided Explanation

### Creating Charts

Charts make data easier to understand at a glance.

**Basic chart creation:**
1. Select the data you want to chart (including headers)
2. Go to Insert tab > Chart
3. Choose chart type (Column, Line, Pie, Bar, etc.)
4. Click OK

**Common chart types:**
- **Column Chart**: Compare values across categories (sales by month)
- **Line Chart**: Show trends over time (stock price)
- **Pie Chart**: Show parts of a whole (market share)
- **Bar Chart**: Compare values horizontally (company comparison)

### Customizing Charts

After creating a chart, you can customize it:

**Chart elements to modify:**
- Title: Double-click chart > Chart Design > Add Chart Element
- Legend: Position, show/hide
- Data labels: Show values on bars
- Colors: Format data series

**Best practices:**
- Use clear, descriptive titles
- Label axes (what does each axis represent?)
- Use colors consistently
- Don't overcomplicate (2-3 data series is usually enough)

### Printing Professional Output

**Print Preview:**
- File > Print Preview
- See how your spreadsheet will look printed
- Adjust margins, orientation, scaling

**Print Settings:**
- Portrait (taller) or Landscape (wider)
- Paper size
- Margins
- Fit to one page (if small enough)

**Headers and Footers:**
- Insert tab > Header & Footer
- Add dates, page numbers, your name

**Print Area:**
- Select the cells you want to print
- Page Layout > Print Area > Set Print Area

## Practical Exercise

**Create a Dashboard-Style Report:**

1. Start with your sales data from Day 3 (Product, Jan/Feb/Mar Sales, Total)

2. **Create a Column Chart:**
   - Select all sales data (A1:D4)
   - Insert > Chart > Column Chart
   - Add title: "Quarterly Sales by Product"
   - Make chart visible and nice looking

3. **Create a Pie Chart:**
   - Select products and totals (A1:A4, E1:E4)
   - Hold Ctrl while selecting non-adjacent data
   - Insert > Chart > Pie Chart
   - Add title: "Sales Breakdown"

4. **Add Summary Section:**
   - Below your data, add:
     - "Total Sales:" with a SUM formula
     - "Average Product Sales:" with an AVERAGE formula
     - "Best Seller:" (the product with highest total)

5. **Format for Print:**
   - Go to Page Layout
   - Set margins to Normal
   - Set orientation to Landscape (to fit charts)
   - Add header with "Sales Report 2024"
   - Add footer with today's date

6. **Print Preview:**
   - File > Print Preview
   - Adjust until it looks professional

7. Save the file
