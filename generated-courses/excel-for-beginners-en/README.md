# Excel for Beginners

## Course Overview

Master the fundamentals of Microsoft Excel in 5 days. This course takes you from spreadsheet basics to creating functional worksheets with formulas, formatting, and data organization.

## Who This Course Is For

- Complete beginners with no Excel experience
- Anyone looking to build essential spreadsheet skills
- Professionals needing to work with data in Excel
- Students preparing for office work environments

## How to Use This Course

1. **Follow the daily structure**: Work through one day per day, but progress at your own pace
2. **Practice as you learn**: Complete all practical exercises before moving forward
3. **Build incrementally**: Each day builds on the previous knowledge
4. **Use real data**: Apply examples to your own work scenarios

## Course Outline

| Day | Title | Focus |
|-----|-------|-------|
| 1 | Getting Started with Excel | Interface, navigation, basic concepts |
| 2 | Creating and Organizing Data | Entering data, formatting cells, basic styling |
| 3 | Essential Formulas | SUM, AVERAGE, IF, COUNT functions |
| 4 | Working with Data | Sorting, filtering, finding information |
| 5 | Presenting Your Data | Charts, advanced formatting, professional output |

## Prerequisites

- Access to Microsoft Excel (any recent version) or Google Sheets
- Basic computer skills (mouse, keyboard, file management)
- Time commitment: 1-2 hours per day

## What You'll Be Able To Do

After completing this course, you will be able to:
- Navigate Excel efficiently and understand the worksheet structure
- Enter, edit, and format data professionally
- Create and use formulas for calculations
- Organize and analyze data using filters and sorts
- Create charts and visualizations
- Print and share your work professionally
