# Excel algajatele

## Kursuse ülevaade

Õpi Microsoft Exceli alused 5 päevaga. See kursus viib sind tabelite loomisest keeruliste valemite ja andmete analüüsini.

## Kellele see kursus on mõeldud

- Täielikud algajad ilma Exceli kogemuseta
- Inimesed, kes soovivad omandada olulisi tabelarvutuse oskusi
- Professionaalid, kes peavad Excelis andmetega töötama
- Õpilased, kes valmistuvad kontoritöö jaoks

## Kuidas seda kursust kasutada

1. **Järgi päevapõhist struktuuri**: Töötage läbi üks päev päevas, kuid liikuge oma tempoga
2. **Harjutage õppimise ajal**: Täitke kõik praktilised harjutused enne edasi liikumist
3. **Ehitage samm-sammult**: Iga päev tugineb eelmisele teadmisele
4. **Kasutage oma andmeid**: Rakendage näiteid oma töö stsenaariumidele

## Kursuse ülesehitus

| Päev | Teema | Fookus |
|------|-------|--------|
| 1 | Alustamine Exceliga | Liides, navigatsioon, põhikontseptsioonid |
| 2 | Andmete loomine ja korraldus | Andmete sisestamine, lahtrite vormindamine |
| 3 | Olulised valemid | SUM, AVERAGE, IF, COUNT funktsioonid |
| 4 | Andmetega töötamine | Sortimine, filtrimine, andmete otsimine |
| 5 | Andmete esitamine | Diagrammid, vormindamine, professionaalne väljund |

## Eeltingimused

- Juurdepääs Microsoft Excelile (ükskõik milline hililine versioon) või Google Sheets
- Põhilised arvutikasutamise oskused
- Aeg: 1-2 tundi päevas

## Mida saad pärast kursust teha

Pärast selle kursuse lõpetamist saad:
- Navigeerida Excelis tõhusalt
- Sisestada, muuta ja vormindada andmeid professionaalselt
- Luua ja kasutada valemeid arvutusteks
- Korraldada ja analüüsida andmeid filtrite ja sortimisega
- Luua diagramme ja visualiseeringuid
- Jagada oma tööd professionaalselt
