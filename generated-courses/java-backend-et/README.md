# Java tagumised arenduse

## Kursuse ülevaade

Õpi Java backend arendamise alused 5 päevaga. See kursus katab Java põhikontseptsioonid, objekti-orienteeritud programmeerimine, rakenduste ehitamine ning failide ja andmebaasidega töötamine.

## Kellele see kursus on mõeldud

- Arendajad, kes on uued Java programmeerimises
- Need, kes üleminekut teistest keeltest Javasse
- Aspireerivad tagumiste arendajad
- Tarkvarainsenerid, kes valmistuvad Java-põhiste projektide jaoks
- Igaüks, kes huvitub robustsete rakenduste ehitamisest

## Kuidas seda kursust kasutada

1. **Järgi päevapõhist struktuuri**: Töötage läbi üks päev päevas oma tempoga
2. **Kirjuta koodi koos**: Täitke kõik kodeerimise harjutused enne edasi liikumist
3. **Ehitage samm-sammult**: Iga päev tugineb eelmisele teadmisele
4. **Harjutage iseseisvalt**: Looge oma näidete variatsioone

## Kursuse ülesehitus

| Päev | Teema | Fookus |
|------|-------|--------|
| 1 | Java alused | Süntaks, muutujad, andmetüübid, operaatorid |
| 2 | Juhtimisvoolu & funktsioonid | If-laused, tsüklid, meetodid |
| 3 | Objekti-orienteeritud programmeerimine | Klassid, objektid, päramine, kapselimine |
| 4 | Andmetega töötamine | Massiivid, kogumid, faili I/O |
| 5 | Rakenduste ehitamine | Erandite käsitlemine, silumine, parimad tavad |

## Eeltingimused

- Põhilised programmeerimisteadmised (muutujad, tsüklid, funktsioonid)
- Java Development Kit (JDK) 11 või uuem paigaldatuna
- Teksti redaktor või IDE (VS Code, IntelliJ, Eclipse)
- Aeg: 2-3 tundi päevas

## Mida saad pärast kursust teha

Pärast selle kursuse lõpetamist saad:
- Kirjutada Java programme, kasutades õiget süntaksit ja konventsioone
- Luua ja kasutada klasse ja objekte tõhusalt
- Mõista ja rakendada objekti-orienteeritud põhimõtteid
- Töötada kogumite ja failandmetega
- Hallata vigu ja silumine Java rakendusi
- Ehitada lihtsaid tagumiste rakendusi
