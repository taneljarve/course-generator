# Course Generator Methodology

## What This Skill Does

Creates **self-paced, Markdown-based learning courses** generated by AI. Perfect for:
- ✅ Any technical skill (programming, frameworks, tools)
- ✅ Business domains (compliance, finance, trading)
- ✅ Soft skills (communication, leadership)
- ✅ Any teachable subject with clear progression

## When to Use This

- Need to quickly generate learning content
- Subject can be broken into day-by-day structure
- Want reusable Markdown course files
- Need courses in multiple languages

# How to Generate a Learning Course

## Phase 1: Gather Requirements

Before generating, gather:

- **Topic**: What subject? (e.g., "Python for Data Science")
- **Language**: What output language? (e.g., "English", "Eesti")
- **Days**: How many days? (1-30, recommend 5-14)
- **Source Text** (optional): Any existing material to ground the course
- **Target Audience**: Beginner, intermediate, advanced?

---

## Phase 2: AI Course Generation

### System Prompt for AI

```
You generate complete learning courses as Markdown files.
Return only valid JSON that matches the provided schema.
The content must read well in a GitHub Markdown preview.
Do not use HTML. Use Markdown headings, bullet lists, tables where useful, fenced code blocks if relevant, and short paragraphs.
The requested language must be used consistently throughout the course.
Create one README overview file plus one standalone day file per day.
Each day markdown must start with a level-1 heading in the form '# Day N: Title'.
Each day file should include these sections in Markdown: Learning Objectives, Key Concepts, Guided Explanation, Practical Exercise, Reflection Questions, and Quick Checklist.
```

### User Prompt Format

```
Topic: [TOPIC]
Language: [LANGUAGE]
Length in days: [DAYS]
[Optional source text instructions]

The README overview should contain:
- A concise course summary
- Who it is for
- How to use the course
- A day-by-day outline table

The day files should be cohesive and practical rather than generic filler.

Return ONLY a valid JSON object with this structure:
{
  courseTitle: "string",
  courseSummary: "string",
  overviewMarkdown: "string",
  days: [
    {
      dayNumber: number,
      title: "string",
      markdown: "string"
    }
  ]
}
```

## Phase 3: Course Structure

### README.md Structure

```markdown
# [Course Title]

[Course summary - 2-3 paragraphs explaining what students will learn]

## Course Overview

| Day | Topic |
|-----|-------|
| 1 | [Topic 1] |
| 2 | [Topic 2] |
| ... | ... |

## Who Is This Course For?

[Target audience description]

## How to Use This Course

[Instructions on how to progress through the course]
```

### Day File Structure

```markdown
# Day N: [Topic]

## Learning Objectives

- ✅ [Objective 1]
- ✅ [Objective 2]
- ✅ [Objective 3]

## Key Concepts

### [Concept A]
[Explanation]

### [Concept B]
[Explanation]

## Guided Explanation

[Teaching content with examples]

## Practical Exercise

### Exercise: [Name]
**What to do:** [Instructions]
**How to verify:** [Success criteria]
**Hint:** [Nudge if stuck]

## Reflection Questions

1. [Question 1]
2. [Question 2]

## Quick Checklist

- [ ] I understand [Concept A]
- [ ] I can [do something]
- [ ] I completed [exercise]
```

## Phase 4: Generation Options

### Option 1: Via Web UI

1. Go to course generator web app
2. Enter topic (or select from dropdown)
3. Select language
4. Set number of days
5. Optionally paste source text
6. Click "Generate"

### Option 2: Via API

```bash
curl -X POST https://[domain]/api/generate-course \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "Python for Data Science",
    "language": "English",
    "days": 5,
    "sourceText": ""
  }'
```

# Course Quality Guidelines

## Principles

1. **Progressive Structure**: Days build on each other
2. **Practical Focus**: Learn by doing, not passive reading
3. **Clear Objectives**: Each day has measurable outcomes
4. **Balanced Length**: Each day = 20-40 minutes of content
5. **Consistent Language**: All content in requested language

## What Makes a Good Course

### README Should
- Clearly state what students will learn
- Explain who the course is for
- Provide day-by-day outline
- Include prerequisites if any

### Each Day Should
- Start with clear learning objectives
- Explain key concepts simply
- Include at least one practical exercise
- End with reflection questions
- Have a checklist for self-assessment

## Common Pitfalls to Avoid

- ❌ Days that are too long (split into multiple days)
- ❌ Days without practical application
- ❌ Missing objectives (unclear what student learns)
- ❌ Jargon without explanation
- ❌ Passive content only (no exercises)
